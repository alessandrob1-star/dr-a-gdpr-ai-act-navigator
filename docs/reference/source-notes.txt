3. Official Journal access point

URL:
https://eur-lex.europa.eu/oj/direct-access.html

Plain English description:
Official access point for the Official Journal of the European Union, where EU legal acts are officially published.

Source:
EUR-Lex

Type:
Official publication source

Use in the project:
Official verification source for checking whether a legal act has been published in the Official Journal of the European Union.

Important note:
EUR-Lex states that, since July 2013, only the electronic edition of the Official Journal published on EUR-Lex is authentic and produces legal effects.

MVP relevance:
This source supports the Regulatory Validation Agent. News items can create early warnings, but official confirmation should rely on publication in official sources such as the Official Journal on EUR-Lex.

4. EUR-Lex Webservice

URL:
https://eur-lex.europa.eu/content/help/data-reuse/webservice.html

Registration URL:
https://eur-lex.europa.eu/protected/web-service-registration.html

Plain English description:
Official EUR-Lex API-like webservice for querying EU legal documents and metadata directly. It is SOAP-based and requires registration.

Source:
EUR-Lex / Publications Office of the European Union

Type:
Official API / webservice

Protocol:
SOAP

Output format:
XML

Access:
Free after registration

Current project status:
Registration submitted. Access is currently pending administrator approval.

Important notes:
EUR-Lex states that registered users can query EUR-Lex directly through the webservice without manually searching the website. The webservice supports query options similar to expert search, including full-text search. It cannot be used to directly download document files.

Use in the project:
Preferred official API for the Official Source Verification Agent. It can be used to check whether EU legal acts, metadata, CELEX identifiers, or regulatory updates appear in EUR-Lex.

MVP fallback while access is pending:
Use stable links, ELI links, Official Journal direct access, and manually collected official documents.

5. EUR-Lex permanent / stable links

URL:
https://eur-lex.europa.eu/content/help/data-reuse/linking.html

Plain English description:
Official guidance explaining how to create permanent links to EUR-Lex documents, Official Journal editions, and pages.

Source:
EUR-Lex / Publications Office of the European Union

Type:
Stable links / data reuse guidance

Access:
No login required

Important notes:
EUR-Lex defines a permanent link, also known as a stable link, as a link that will not change over time and guarantees ongoing access to the linked content. Permanent links can point to website pages in a specific language, specific Official Journal editions, or specific documents using identifiers.

Use in the project:
Official fallback for stable references to GDPR, the EU AI Act, Official Journal publications, and cited documents when API access is pending or not required.
