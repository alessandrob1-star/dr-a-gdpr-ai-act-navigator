# Deterministic Company Memory Services

`company_memory_agent.py` contains the auditable domain logic used by the
Company Profile Agent and Regulatory Matching Agent. Despite the legacy
filename, it is a deterministic service module rather than a standalone LLM
agent.

## Responsibilities

- validate the complete questionnaire contract;
- normalize company, AI-use, privacy, transfer, and governance answers;
- derive GDPR and AI Act relevance tags;
- identify existing and missing controls;
- build an assessment trace linked to triggering answers;
- calculate the attention score;
- generate warnings and warning-to-control links;
- match regulatory events and monitored feed items;
- build the personalized AI Act timeline;
- write reviewable CLI JSON artifacts.

The runtime model is not called from this module. Dr. A model orchestration is
centralized in `module_agents/dr_a_agent.py`, ensuring that every conversational
answer uses the same Policy Agent and grounding checks.

## Demo profiles

`demo_profiles/` contains:

- `01_low_risk_saas.json`;
- `02_hr_ai_high_risk.json`;
- `03_gpai_provider.json`.

Run all three deterministic profiles from the repository root:

```powershell
python module_company_profile/memory_agent/run_demo_profiles.py
```

Each profile produces different tags, scores, warnings, controls, and matched
events under `demo_outputs/`.

## Run one questionnaire from the command line

```powershell
python module_company_profile/memory_agent/company_memory_agent.py `
  module_company_profile/memory_agent/demo_profiles/02_hr_ai_high_risk.json `
  --out storage/company_profile/output
```

Outputs:

- `company_memory.json`;
- `dashboard_context.json`;
- `model_prompt.txt`.

`model_prompt.txt` is a review artifact generated by the deterministic
CLI. The running dashboard does not send it to the model; Dr. A builds a smaller
question-specific context at request time.

## Docker CLI service

Place a questionnaire at:

```text
storage/company_profile/input/questionnaire_answers.json
```

Then run:

```powershell
docker compose -f module_company_profile/docker-compose.yml run --rm memory-agent
```

The interactive application itself is available through the `dashboard`
service or the local launchers documented in `docs/INSTALLATION.md`.

## Trust boundary

- The model cannot change scores, tags, warnings, or timelines.
- Missing facts stay unknown rather than being inferred.
- Browser-supplied derived results are rebuilt from questionnaire answers.
- Outputs support review and prioritization, not legal certification.
